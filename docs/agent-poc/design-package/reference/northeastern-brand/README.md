# Northeastern Brand Reference Assets

Downloaded 2026-07-06 for the private CS7980 Moses / concierge AI design exploration.

These files are reference materials from Northeastern public brand and news pages. They are
not new project-owned assets, and they should not be treated as approved public product
branding. Public use should go through Northeastern Brand Review.

## Design Notes For Moses

- Use Northeastern black/white as the foundation.
- Use Northeastern red `#C8102E` as a restrained accent.
- Treat the King Husky material as inspiration for the Moses character, not as a license to
  alter official mascot marks.
- For public demos, avoid official logos/marks until Brand Review approval.
- Prefer a custom Moses mark for the class project, with copy such as "student project
  inspired by Northeastern's King Husky tradition."
